Интерактивное 3D-созвездие проектов, заметок и экспериментов. Вместо привычного плоского резюме — пространственная карта на Three.js с физикой пружин, звуковым генератором в ре миноре и досье в трёх оптиках.

## Концепт

Каждый куб — это проект или мысль, живущая в своём кластере (`разработка`, `арт`, `продукт`, `учёба`, `заметки`, `ссылки`). Кубы удерживаются пружинными связями, реагируют на курсор и касания, воспроизводят свои гармоники и открывают карточку-досье с эффектом терминальной печати.

Карточки разделены на три слоя:
- **для любопытных** — авторский контекст, замысел и личный интерес к задаче;
- **для нанимающих** — контекст задачи, предпринятые действия и конкретный результат;
- **для инженеров** — стек и архитектурные решения в формате «что и зачем».

## Что под капотом

### Zero-build архитектура
- **Без npm, сборщиков и зависимостей.** Чистые ES-модули, запускающиеся напрямую в браузере.
- `vendor/`: вендоринг Three.js r170 (с модулями EffectComposer) и колориметрической библиотеки Culori.
- Мгновенный деплой на GitHub Pages через обычный `git push`.

### Звуковой движок (Web Audio API)
- Саунд-дизайн в ре миноре: длинные затухающие обертоны (вайб Рюити Сакамото) в сочетании с сухими цифровыми щелчками и зерном (в духе Alva Noto).
- Генеративные ритмические рисунки: `удар`, `рваный`, `ноты`.
- Синхронный `primeSound` на первое касание для надёжного старта на мобильных устройствах (iOS Safari / WebKit).

### Цвет в OKLCH и живая фавиконка
- Все цвета рассчитываются в перцептивно равномерном пространстве OKLCH через Culori: яркость остаётся стабильной при любых оттенках.
- Динамическая SVG-фавиконка: на лету стримит в `<link rel="icon">` плавный градиент между кластерами из основного цикла рендера.

### Двуязычность (i18n)
- Поддержка `ru` и `en` для всех досье и элементов интерфейса.
- Автоопределение языка по настройкам браузера гостя (`navigator.languages`), ручной переключатель в один клик и сохранение выбора в `sessionStorage`.

## Структура проекта

```
my-website/
├── index.html        # Разметка, стили, импортмапы и UI-контролы
├── js/
│   ├── main.js       # Сцена Three.js, физика кубов, постпроцессинг, логика досье
│   ├── content.js    # Данные досье, слои, переводы (ru/en), UI-словарь
│   ├── sound.js      # Синтез Web Audio API, генератор ритмов, голоса кубов
│   ├── palette.js    # OKLCH-палитра категорий и сэмплирование цвета
│   └── favicon.js    # Анимированная фавиконка в табе браузера
└── vendor/           # Three.js r170, addons, culori
```

## Локальный запуск

Так как проект не требует сборки, подойдёт любой локальный веб-сервер (нужен для корректной работы ES-модулей):

```bash
# через Python
python3 -m http.server 8000

# или через Node
npx serve .
```

Открыть в браузере: `http://localhost:8000`
